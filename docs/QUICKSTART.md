# Quick Start

← [กลับหน้าหลัก](../README.md)

---

**1. Clone repository**

```bash
git clone https://github.com/<your-username>/SP-MiniProject.git
cd SP-MiniProject
```

**2. สร้าง Virtual Environment**

```bash
python -m venv venv
```

**3. Activate**

```bash
# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

**4. ติดตั้ง dependencies**

```bash
pip install -r requirements.txt
```

**5. รัน**

```bash
python app.py
```

**6. เปิดเบราว์เซอร์**

```
http://localhost:5000
```

> ออกจาก env เมื่อเลิกใช้งานด้วย `deactivate`
