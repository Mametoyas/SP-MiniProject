CHAT 01 — SELECTING THE AI CONCEPT
================================================================================

USER
----
ต้องการทำเกม Hangman ร่วมกับ AI ควรเลือก AI แบบใด

AI RESPONSE — OPTIONS DISCUSSED
-------------------------------
1. AI Hint        : ให้คำใบ้แทนการเฉลยคำตอบ
2. AI Opponent    : ให้ AI ผลัดกันเดาคำแข่งกับผู้เล่น
3. AI Difficulty  : ปรับระดับความยากของคำศัพท์และคำใบ้
4. AI Teacher     : อธิบายความหมายและตัวอย่างของคำศัพท์หลังจบเกม
5. AI Story Mode  : สร้างเรื่องราวต่อเนื่องตามการเดา

DECISION
--------
เลือกแนวทาง "AI Hint + AI Opponent" เพื่อให้ผู้เล่นได้รับคำแนะนำในโหมด
AI Assist และแข่งขันกับ AI ในโหมด VS AI

PROJECT IMPACT
--------------
- มี 3 โหมด: Classic, AI Assist และ VS AI
- AI ไม่เฉลยคำตอบ แต่เสนออักษรที่ควรเดา
- ผู้เล่นยังเป็นผู้ตัดสินใจเลือกอักษรเอง

CHAT 02 — CHOOSING AI WITHOUT AN LLM
================================================================================

USER
----
มีวิธีใช้ AI ที่ไม่ใช่ LLM หรือไม่

AI RESPONSE — OPTIONS DISCUSSED
-------------------------------
- Pattern Matching + Frequency Analysis
- Naive Bayes
- Decision Tree
- Reinforcement Learning
- Genetic Algorithm
- Neural Network

REASONING
---------
สำหรับ Hangman การเริ่มจากคลังคำศัพท์และ pattern ของคำทำให้ตรวจสอบได้ว่า
AI เลือกอักษรจากอะไร ตัวอย่างเช่น pattern "_a__a_" จะกรองเฉพาะคำที่มีรูปแบบ
ตรงกัน จากนั้นจึงหาตัวอักษรที่มีโอกาสปรากฏสูง

DECISION
--------
ใช้ Pattern Matching เป็นแนวคิดหลักในการสร้างข้อมูล และใช้โมเดล Machine Learning
ขนาดเล็กเพื่อทำนายอักษร โดยไม่ต้องใช้ LLM หรือ API ภายนอก

PROJECT IMPACT
--------------
- ข้อมูลมาจากไฟล์ words.txt ภายในโครงงาน
- อธิบาย input และผลลัพธ์ของ AI ได้ชัดเจน
- ไม่มีความจำเป็นต้องส่งข้อมูลผู้เล่นไปยังบริการภายนอก

================================================================================
CHAT 04 — DATASET REQUIREMENTS
================================================================================

USER
----
หากต้องการไฟล์โมเดล hangman_ai.pkl จำเป็นต้องใช้ข้อมูลหรือไม่

AI RESPONSE
-----------
โมเดลประเภท Decision Tree และ Naive Bayes ต้องมี dataset สำหรับเรียนรู้ความสัมพันธ์
ระหว่างสถานะของเกมกับอักษรที่ควรเดา ข้อมูลสามารถสร้างจากคลังคำศัพท์ได้ ไม่จำเป็น
ต้องจัดทำด้วยมือ

DESIGN APPLIED
--------------
แต่ละแถวข้อมูลเก็บสถานะที่ AI ต้องใช้ตัดสินใจ:

  pattern         รูปแบบคำปัจจุบัน เช่น "_e___"
  guessed         อักษรที่เดาถูกแล้ว
  wrong           อักษรที่เดาผิดแล้ว
  length          ความยาวคำ
  revealed        จำนวนอักษรที่เปิดเผยแล้ว
  candidate_count จำนวนคำที่ยังเป็นไปได้
  label1..label5  อักษรแนะนำตามลำดับ

PROJECT IMPACT
--------------
- ใช้ datasets/words.txt เป็นแหล่งคำศัพท์
- สร้าง datasets/hangman_dataset.csv ด้วย codes/make_dataset.py
- ใช้ set เพื่อเก็บอักษรไม่ซ้ำ และป้องกันการแนะนำอักษรที่ใช้ไปแล้ว


================================================================================
CHAT 05 — GENERATING STATES, TRAINING AND COMPARING MODELS
================================================================================

USER
----
ต้องการสร้าง dataset ให้ครอบคลุมรูปแบบของแต่ละคำ เช่น zebra สามารถมี pattern
z____, _e___, __b__, ze___ และรูปแบบอื่น ๆ รวมทั้งต้องการเทรนและเปรียบเทียบโมเดล

AI RESPONSE — APPROACH ADOPTED
-------------------------------
1. อ่านคำศัพท์และทำความสะอาดข้อมูล
2. ใช้ set(target) หาอักษรที่ไม่ซ้ำในคำ
3. สร้าง combinations ของอักษรที่เปิดเผย เพื่อได้หลาย pattern ของคำเดียวกัน
4. สุ่ม/เลือกอักษรที่เดาผิดจากอักษรที่ไม่ได้อยู่ในคำนั้น
5. กรอง candidate words ที่มีความยาวและ pattern ตรงกัน
6. นับอักษรที่ยังไม่ถูกใช้ใน candidate words เพื่อสร้าง label แนะนำ
7. เทรนและเปรียบเทียบ Decision Tree, Logistic Regression และ Naive Bayes

PROJECT IMPLEMENTATION
----------------------
  codes/make_dataset.py  สร้าง dataset จาก words.txt
  codes/train_models.py  เทรนและบันทึกโมเดล
  codes/eval_models.py   ประเมินและเปรียบเทียบโมเดล
  codes/predict.py       โหลดโมเดลและส่งคืนคำแนะนำสูงสุด 5 ตัวอักษร

INTEGRATION RESULT
------------------
AI รับ pattern, guessed และ wrong จากสถานะเกม แล้วคืนคำแนะนำให้:

  - AI Assist : ผู้เล่นเห็นคำแนะนำและเลือกเดาเอง
  - VS AI     : AI ใช้คำแนะนำอันดับแรกเป็นอักษรที่เดาใน turn ของตน
